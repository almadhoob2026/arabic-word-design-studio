# Core layout rules — v1.1 (Arabic DOCX)

These rules are the default contract for **new documents generated by this project**. They do not authorize destructive normalization of user-provided DOCX files, tracked changes, fields, or mixed LTR content.

| Area | Default | Word / OOXML meaning | Rationale |
| --- | --- | --- | --- |
| Body text / headings | 0 pt first-line, left and right indents | `w:ind` reset in named paragraph styles | Prevent accidental inheritance from Word templates |
| Text within table cells | 0 pt first-line, left and right indents | explicit paragraph `w:ind` | Cell spacing must come from padding, not a second indent |
| Table cell paragraph spacing | 0 pt before and after | `w:spacing @before/@after=0` | Avoid uneven row heights and blank gaps |
| Table cell line spacing | 1.14 | paragraph line spacing | Provides consistent Arabic leading |
| Table horizontal inner padding | 155 twips (about 2.73 mm) | `w:tcMar` start/end **and** left/right | Robust across Word and LibreOffice |
| Table vertical inner padding | 85 twips (about 1.50 mm) | `w:tcMar` top/bottom | Avoid cramped table rows |
| Bullet list indentation | 0.55 cm from **right** | paragraph right indent | Correct Arabic anchor |
| Bullet hanging offset | 0.38 cm toward right margin | negative first-line indent / `w:hanging` | Keeps wrapped continuation text aligned |
| After-table spacing | 5 pt | explicit `Studio Spacer` | Avoid full-size empty paragraphs that push tables to new pages |
| Compound dates and ranges | selective LRM with Word bidi enabled | text controls + `w:rtl` / `w:bidi` | Avoid visual reversal of `2026–2027` |
| Table header bold | normal + complex-script bold | `w:b` + `w:bCs` | Correct Arabic font weight |

## Directional invariants
1. Table order: `w:bidiVisual=1`; cell contents: `w:bidi=1`.
2. Do **not** use `left_indent` to offset Arabic bullets. Use `right_indent`, plus a hanging first line.
3. If Word or LibreOffice ignores `start/end` cell margins, `left/right` must still provide equivalent padding.
4. Do not use arbitrary Unicode RTL markers across whole paragraphs. The numeric helper addresses only embedded LTR numeric compounds.
5. Never achieve fit solely by shrinking Arabic fonts below legibility. Revise layout/content instead.

## Quality regression
Run `pytest -q`, regenerate all four examples, run `scripts/audit_docx.py`, then visually inspect **all** pages. Any spacing-token change must re-run this matrix and check at least one overflowing/multiline cell fixture.
